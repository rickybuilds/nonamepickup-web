# 1999 LEGENDARY TERMINAL — NoNamePUGs

The ultimate 1999 TFC veteran experience.

## Concept
A pure 1999 terminal / BBS / game console client for the NoNamePUGs community.

- Boot sequence + authentic terminal login window
- Full CRT scanlines, phosphor glow, blinking cursors
- Web Audio 1999 sounds (modem handshake, beeps, rockets, explosions)
- Canvas particles (dust, flags, muzzle flashes, grenade bursts)
- Three.js low-poly waving TFC flag / tactical display
- Command-line driven navigation (type "live", "ranks", "join", etc.)
- Real data from the live API (queue, leaderboard, maps, stats, matches)
- Multiple dedicated terminal pages: Live Ops, Ranks, Maps, Hall of Fame

Everything lives in this folder. No changes to the original API or old site.

## How to use
1. Open `index.html`
2. Watch the 1999 boot sequence
3. Enter any handle + "access code" and click CONNECT (or press Enter)
4. You are now inside the legendary terminal.
5. Use the top menu or the command bar at the bottom (`help`, `live`, `join`, `disconnect`...)
6. Click "JOIN PICKUP NOW" for the explosive 1999 deployment sequence.
7. Visit the other .html files for dedicated terminal screens (Live Ops, ELO Ranks, etc.).

## API Usage
All data comes live from the existing NoNamePUGs API (read-only).
- Queue, Leaderboard, Map averages, Stats, Matches, Player search, etc.

The API code was never touched.
