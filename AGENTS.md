# Repository Instructions

- Do not create new test files.
- Do not add to or modify existing test files unless the user explicitly asks for test changes.
- Do not run tests unless the user explicitly asks for them.
- Commit and push all completed task changes to Git by default, including code, documentation, and repository rule updates, unless the user explicitly asks otherwise. Do not leave completed work only in the local checkout or ask again for permission to commit or push.
